# 品牌官号公众号排版器（WeChat Article Formatter）

为品牌方官方公众号（如「NVIDIA 英伟达」）设计的排版工具：把写好的文字粘贴进来，**一键排成风格固定的成品版式**，复制后直接粘贴到公众号编辑器，样式不丢失。

---

## 一、快速体验（非技术用户 3 步上手）

1. 打开 `index.html`（双击即可，无需安装任何东西，纯前端、可离线运行）
2. 粘贴你的文字 → 点击「**✦ 一键排版**」
3. 点击「**复制到公众号**」→ 到公众号编辑器里 `Ctrl/Cmd + V` 粘贴

**一键演示入口**（打开即自动演示，无需手动操作）：

| 入口 | 效果 |
| --- | --- |
| `index.html?demo=raw` | 自动载入「排版前」原始文案（含多余空行、半角标点），展示清洗前状态 |
| `index.html?demo=formatted` | 自动完成「清洗 → 排版 → 预览」全流程，直接看到成品 |

> 在线体验链接见文末（若已部署）。

## 二、功能清单

- **多套品牌模板**：内置「英伟达绿·科技风」「深海蓝·商务风」「暖阳橙·活力风」「墨影黑白·极简编辑风」4 套固定风格，右上角一键切换，切换后预览实时更新。
- **品牌配色定制器**：点击「自定义」，输入你的品牌主色（如 `#E60012`），工具自动推导深色/浅背景/按钮字色，实时生成第 5 套专属模板，并持久保存到本地。
- **发布前敏感词检查**：内置广告法极限词、医疗夸大词、投资诱导词、诱导分享词库；排版后自动扫描，命中词标红并给出替换建议，降低公众号发布被拒风险。
- **敏感词点击定位**：右侧检查项可直接点击，预览区自动高亮并滚动到该词位置，原文输入区光标同步定位，方便逐处确认修改。
- **手机端适配**：窄屏自动切换为「输入 → 预览 → 检查」单列布局；≤640px 顶栏两行化，模板横向滑动，输入区 16px 防止 iOS 聚焦缩放，主按钮全宽大触控目标，底部 Toast 避开刘海安全区。
- **智能清洗**：自动去 BOM/零宽字符、合并 3 行以上连续空行、规范中英文标点（`，。：；！？“”（）`），无需手动调整。
- **自动结构识别**：识别标题、小标题、正文段落、引文、重点强调、列表、分隔线、文末注，统一生成模板规定的字号、行距、字色、对齐方式。
- **成品预览**：手机尺寸预览框，所见即所得（预览内容 = 复制内容）。
- **一键复制到公众号**：复制富文本 HTML（全部内联样式），粘贴后样式保留；兼容 Chrome / Edge / Safari / Firefox。
- **附加能力**：字数与阅读时长统计、清洗报告、下载 HTML、`Ctrl+Enter` 快捷排版。

### 结构标记规则（可选，不写也会自动识别）

| 标记 | 作用 | 自动识别兜底 |
| --- | --- | --- |
| `#` / `##` / `###` | 一级/二级/三级小标题 | 短句（≤24 字）且后接空行、不以句末标点结尾 → 小标题 |
| `>` | 引文 | — |
| `**文字**` | 行内品牌色加粗 | — |
| 整行 `**文字**` | 重点强调框（品牌色底） | — |
| `- ` / `1. ` | 列表 | 以 `-` `•` `1.` 开头自动识别 |
| `---` | 分隔线 | — |
| `文｜` / `来源：` 开头 | 文末注（灰色小字） | — |
| 首行短句（≤30 字） | — | 自动识别为标题 |

> 提示：不希望某句短句被误判为小标题时，在句尾加上句号即可。

## 四、运行说明

- **直接运行**：双击 `index.html`（Chrome / Edge 效果最佳）。
- **本地服务（可选）**：`npx serve . -l 8080` 或 `python -m http.server 8080`，然后访问 `http://localhost:8080`。
- **自测**：`node test.js`（验证清洗、结构识别、HTML 渲染是否符合预期）。

## 五、技术选型与原理

| 项 | 选型 | 理由 |
| --- | --- | --- |
| 框架 | 原生 HTML/CSS/JS（零依赖） | 双击即用、离线可用、无构建步骤，非技术用户零门槛 |
| 复制保样式 | `navigator.clipboard.write` + `ClipboardItem`（`text/html`） | 复制富文本；不支持时自动降级 `execCommand('copy')` |
| 移动端 | `viewport-fit=cover` + `env(safe-area-inset-*)` + 响应式断点 | 适配刘海屏、iOS 聚焦不自动缩放、大触控目标 |
| 公众号兼容 | 产物全部为**内联样式**（`<section>/<p>/<span>`，不使用 class、background-image 等公众号会剥离的属性） | 与秀米/135 编辑器同原理，粘贴后样式保留 |
| 预览 | iframe `srcdoc` 渲染与复制内容完全一致的 HTML | 所见即所得 |
| 结构识别 | 规则引擎（显式标记优先 + 启发式兜底） | 无需训练、结果可预期、可解释 |

**兼容性**：Chrome / Edge（最佳）、Firefox、Safari 13.1+（复制功能依赖浏览器剪贴板能力，旧版浏览器会自动降级为选中复制）。

## 六、如何扩展模板（开发者）

在 `js/templates.js` 的 `TEMPLATES` 对象中追加一个条目即可，例如：

```js
myBrand: {
  id: "myBrand",
  name: "我的品牌 · 风格名",
  desc: "一句话描述",
  accent: "#FF0000", accentDeep: "#B00000",
  headingColor: "#111111", bodyColor: "#333333", captionColor: "#999999",
  quoteBg: "#FFF5F5", quoteBar: "#FF0000", calloutBg: "#FFEBEB",
  dividerColor: "#FF0000", bg: "#FFFFFF",
  titleSize: 20, h2Size: 17, h3Size: 15.5, h4Size: 14.5,
  bodySize: 15, quoteSize: 15, captionSize: 13,
  lineHeight: 1.85, align: "left", radius: 8, divider: "· · ·"
}
```

保存刷新页面，右上角即出现新模板。
